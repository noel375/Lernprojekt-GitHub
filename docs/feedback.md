# Feedbackprozess
 
## Ziel
Jede Änderung wird geprüft, bevor sie als fertig gilt. So finden wir Fehler früh und lernen voneinander.
 
## Ablauf
1. Wer eine Aufgabe fertig hat, schreibt einen Kommentar ins Issue.
2. Eine andere Person aus dem Team prüft die Arbeit.
3. Das Feedback wird als Kommentar im Issue geschrieben.
4. Wenn nötig, wird die Arbeit verbessert.
5. Erst wenn alles passt, wird das Issue geschlossen und die Karte kommt nach **Done**.
 
## Regeln für Feedback
- Freundlich und konkret bleiben
- Sagen, was gut ist und was man verbessern kann
- Bei Fragen direkt im Issue nachfragen
