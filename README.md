# Lernprojekt-GitHub
 
## Ziel des Projekts

Dieses Projekt ist eine Übung für das ZLI. Ich lerne, wie man mit GitHub Projects arbeitet: Aufgaben als Issues erstellen, sie auf einem Kanban-Board planen und den Fortschritt verfolgen.
 
## Projektstruktur

- `src/` – hier kommt der Code hin

- `docs/` – hier kommt die Dokumentation hin

- `README.md` – diese Datei mit den wichtigsten Infos
 
## Arbeitsablauf

1. Jede Aufgabe wird als Issue erstellt.

2. Das Issue kommt auf das Board `Lernprojekt-Board`.

3. Die Karte wandert von **To do** über **Doing** nach **Done**.

4. Fortschritt wird mit Kommentaren im Issue dokumentiert.
